- Nueva interfaz InjectFlow basada en HTML/CSS/JavaScript dentro de PyWebView.
- Loading screen nativo en Python.
- Drag & Drop y selector nativo de archivos.
- Resul.csv opcional con deteccion automatica de Solo Param.dat.
- Generacion real conectada al motor Python validado.
- Barra de progreso con modo indeterminado durante la fase larga de Excel.
- Historial integrado en la interfaz, con apertura de hojas anteriores y borrado de registros.
- Vista previa real de la hoja generada durante la sesion actual.
- Boton Abrir hoja habilitado solo despues de generar en la sesion actual.
- Acciones principales organizadas en layout 2x2.
- Dialogos de exito, advertencia, error, confirmacion y procesamiento.
- Soporte responsive y modo oscuro del sistema.

CORRECCION RC1.2
- Corregido empaquetado PyInstaller de pywin32: win32timezone se incluye como hidden import.

- Esta correccion resuelve el fallo runtime: No module named 'win32timezone' durante operaciones COM de Excel.

- La seccion Detalles del popup de generacion tiene ahora una altura maxima responsiva y scroll vertical interno.

- Ajuste exclusivamente visual; no modifica el motor, la generacion Excel, Data.xlsx, Mapeo.xlsx ni las plantillas.
